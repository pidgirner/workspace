# Product Roadmap (предложение)

## Phase 0 — Foundation (сейчас)

- Каркас PWA и UX-концепт модулей.
- Архитектура и доменные границы.
- Черновик контракта mail интеграции.

## Phase 1 — MVP

- Аутентификация и базовые роли.
- Чаты: каналы, сообщения, уведомления.
- Задачи: CRUD, статусы, дедлайны.
- Календарь: события и напоминания.
- Mail integration v1: входящие уведомления + ручная маршрутизация.

## Phase 2 — Командные сценарии

- Треды, упоминания, расширенный поиск.
- Автоматизации задач и SLA.
- Двусторонняя синхронизация календаря.
- Правила auto-triage для почты.

## Phase 3 — Enterprise-grade

- SSO/SAML, расширенный аудит.
- Политики хранения и compliance.
- Аналитика продуктивности команды.
- SDK и публичные интеграции.
