# Team Workspace (рабочий MVP)

Это уже не просто экран-описание: текущая версия даёт базовый **рабочий интерфейс** для команды в формате PWA.

## Что работает сейчас

- **Мессенджер:** отправка сообщений (локальное хранение).
- **Задачи:** создание, отметка выполнено/в работе, удаление.
- **Календарь:** создание событий с проверкой дат.
- **Почта Beget:** сохранение рабочих SMTP/IMAP параметров в форме.
- **PWA:** service worker + manifest + install prompt.

## Быстрый запуск

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`.

## Ограничения текущего MVP

- Пока нет серверной синхронизации между пользователями (данные в localStorage).
- Почтовая форма пока сохраняет конфиг локально, без фактической отправки/получения.
- Supabase-схема готова в `supabase/schema.sql` для следующего шага backend-разработки.

## Структура

- `index.html` — рабочий UI с вкладками модулей.
- `styles.css` — адаптивный стиль интерфейса.
- `app.js` — бизнес-логика модулей, localStorage, PWA install flow.
- `sw.js` — оффлайн-кэширование shell.
- `manifest.webmanifest` — PWA-манифест.
- `supabase/schema.sql` — схема БД под Supabase.
- `docs/` — архитектура, почта, roadmap, публикация.
